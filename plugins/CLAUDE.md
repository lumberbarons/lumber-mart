Plugin source directories for the lumber-mart marketplace.

| Directory | What | When to read |
|-----------|------|--------------|
| `specbeads/` | Spec-driven workflow plugin | Working on spec-kit/beads integration, raise-beads, or spec conformance checks |
| `runbooks/` | Operational runbook plugin | Creating or maintaining operational runbooks |
| `critique/` | Code/test/docs review plugin | Reviewing code, tests, or documentation for quality issues |
| `decisions/` | ADR authoring plugin | Creating or maintaining Architectural Decision Records (the policy layer above specs) |
| `hew/` | GitHub Issues tracking plugin | Filing review findings as issues, or changing the review-key dedup scheme |
| `work-epic/` | Epic orchestration plugin | Changing how epics fan out to herdr agents, or the resolver's spawn policy |
| `lightspec/` | Spec pipeline plugin | Changing the spec format, the approve gate, or the spec-to-epic mapping |
